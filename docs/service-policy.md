# 서비스 정책 (Service Policy)

TrendFit의 정책을 회원 / 옷장 / 트렌드 수집 / 추천 / 구매 연동 5개 영역으로 나눈다.

> 🔸 표시는 **아직 결정되지 않은 항목**이다. 임의로 값을 정하지 말고 → **[open-decisions.md](open-decisions.md)** 를 따른다.

---

## 1. 회원 정책

| 항목 | 정책 |
|---|---|
| 인증 방식 | Google OAuth2 |
| 세션 관리 | JWT 액세스 토큰 + 리프레시 토큰 |
| 권한 | `enum Role { USER, ADMIN }` |
| 온보딩 필수 단계 | 스타일 취향 선택(최소 1개 이상) |
| 온보딩 선택 단계 | 체형 정보 입력 |

- 🔸 온보딩 스타일 태그 목록(구체적 태그명, 개수)은 **미결정** → [open-decisions.md](open-decisions.md)

---

## 2. 옷장 등록 정책

| 항목 | 정책 |
|---|---|
| 등록 방식 | 다중 이미지 일괄 업로드 |
| 1차 분석 | Claude Vision — 카테고리/색상/패턴/크롭 좌표 |
| 보정 방식 | 핏/재질 등 확신도 낮은 속성은 스와이프 UI로 사용자가 즉시 확정 |
| 이미지 처리 범위 | **크롭까지만** (완전 배경 제거/누끼는 MVP 범위 밖, 스트레치) |
| 최소 등록 벌 수 | 🔸 미결정 — "추천 가능" 상태로 전환되는 최소 옷장 규모 |
| '+1 아이템' 자동 등록 | 구매 확정 콜백 수신 시, Vision 재호출 없이(이미 태그를 알고 있으므로) 즉시 등록 |

- 옷장은 온보딩 시 전량 등록을 요구하지 않는다. 소량(5~10벌)으로 시작해 지속 등록 및 구매 연동
  자동 등록으로 점진적으로 채워지는 것을 기본 정책으로 한다.
- 🔸 이미지 저장소(로컬 파일시스템 vs 클라우드 스토리지) 미정 → [open-decisions.md](open-decisions.md)

## 3. 트렌드 수집 정책

| 항목 | 정책 |
|---|---|
| 수집 주기 | 1일 1회 배치 (매일 새벽) |
| 수집 대상 | 로그인 불필요한 **공개** 패션 매체/RSS만 |
| 수집 제외 | 로그인 필요 SNS(인스타그램, 핀터레스트 등) — 이용약관 리스크로 MVP 제외 |
| 정제 방식 | Claude API로 컬러/아이템/무드 키워드 구조화 |
| 원문 처리 | 원문 재배포 금지, 요약·키워드 정제만 저장 |

- 🔸 최종 수집 소스 목록(구체적 매체명, 개수) 미정 → [open-decisions.md](open-decisions.md)

## 4. 추천 정책

| 항목 | 정책 |
|---|---|
| 요청 유형 | (a) 일반 요청("오늘 뭐 입지?") (b) 앵커 아이템 요청("이거 입고 싶은데 뭐랑 매치?") |
| 입력 컨텍스트 | 오늘 날씨 + 최신 트렌드 키워드 + 사용자 취향 + 옷장 전체(ID+태그) |
| 처리 방식 | 프롬프트 조립(Context Injection) — 벡터DB 기반 RAG 사용 안 함 |
| 출력 | 의류 ID 기반 코디 조합 + 필요 시 '+1 아이템' 제안 (JSON) |
| 결과 표시 | 서버가 ID를 실제 이미지로 매핑, 클라이언트에는 사진으로 표시(텍스트 아님) |
| 요청 빈도 제한 | 🔸 미결정 (무료 사용자 하루 N회 등) |

- 추천 엔진의 프롬프트 조립 대상은 [domain-design.md](domain-design.md) §2의 포트(`ClosetQueryPort`,
  `TrendQueryPort`, `UserPreferencePort`)를 통해서만 조회한다.

## 5. 구매 연동 정책

| 항목 | 정책 |
|---|---|
| '+1 아이템' 표시 | 추천 결과에 쇼핑 링크 카드로 함께 제안 |
| 제휴 방식 | 제휴 링크 경유 구매 시 수수료 수취(장기 수익 모델) |
| 자동 등록 | 구매 확정 콜백 수신 시 `ClosetCommandPort`를 통해 `ClothingItem`(source=AUTO_PURCHASE) 자동 생성 |

- 🔸 제휴 대상 쇼핑몰/제휴 프로그램 미정 → [open-decisions.md](open-decisions.md)
